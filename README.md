# Bank Account System

**Автор:** Бледных Юрий

## Краткое описание

Консольное приложение для управления банковскими счетами, поддерживающее различные типы счетов (расчетный, сберегательный, кредитный), историю транзакций в виде очереди, фильтрацию операций, сохранение/загрузку данных в JSON.

### Возможности:
- Создание трех типов счетов
- Депозит, снятие, перевод средств
- История транзакций (очередь)
- Фильтрация по дате, типу, счету
- Сохранение/загрузка в JSON
- Обработка ошибок (недостаточно средств, некорректный ввод)
